# Intelligent Link

Intelligent Link is a lightweight plugin that automatically redirects all external links through a destination page you configure. Useful for tracking, link protection, ad-friendly redirects, or routing users through an intermediate page.

## Features

Automatically detects external links

Redirects them through a custom URL

Simple configuration page

Lightweight and easy to install

## Installation

Download the ZIP file from the releases section or clone the repository.

Upload the ZIP file to your website’s admin panel:

Navigate to Plugins → Add New

Click Upload Plugin

Select the ZIP file and install

Activate the plugin.

## Configuration

After activation, open the Intelligent Link menu in the admin sidebar.

Enter the redirect URL you want all external links to pass through.

Save your settings.

## How It Works

Once configured, any external link on your site will automatically be routed through the redirect page you specified.
